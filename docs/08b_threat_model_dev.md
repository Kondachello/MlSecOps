# 08b — Рабочие карточки угроз (план реализации атаки и митигации)

> Развёрнутые карточки для разработки. Глянцевый паспорт (8 колонок) — в
> [`08_THREAT_MODEL.md`](08_THREAT_MODEL.md). Здесь к каждой угрозе добавлены **инженерные поля**:
> Нарушитель, Кто делает (роль в команде), План реализации (атака + митигация), Демо-сценарий.
> `[приманка]` = что специально подкладываем для демонстрации срабатывания гейта (только в `demo/`).

Приоритеты: **P0** (MVP) → **P1** → **P2** → **P3** (GenAI). Маппинг гейтов — [`07_SECURITY_GATES.md`](07_SECURITY_GATES.md).

## P0 — MVP

### #10 — Секреты в ML-коде (hardcode)
- **Актив:** исходный код (`train_m1.py`). **Поверхность:** CI/CD (PR), git. **Уязвимость:** нет скана секретов.
- **Угроза:** утечка креденшелов БД/API. **Последствия:** компрометация прод-БД, штраф. **Риск:** Высокий.
- **Техники:** T1552. **Gate:** **G2** gitleaks.
- **Нарушитель:** инсайдер / внешний при утечке репо. **Кто делает:** DS (приманка), MLSecOps (сканер).
- **План атаки:** `[приманка]` в `demo/insecure/leaky.py`: строка вида `API_KEY = "<FAKE-DEMO-PLACEHOLDER>"`.
- **План митигации:** CI-шаг `gitleaks detect --source . --report-format json`; detect → exit 1; отчёт → `findings`.
- **Демо:** PR краснеет; в UI находка с правилом и (замаскированной) строкой.

### #8 — CVE в ML-библиотеках
- **Актив:** среда исполнения, `requirements.txt`. **Поверхность:** CI/CD, supply chain. **Уязвимость:** устаревшие либы.
- **Угроза:** RCE/DoS через известную CVE. **Последствия:** компрометация контейнера, простой. **Риск:** Высокий.
- **Техники:** T1195.002. **Gate:** **G2** pip-audit (+trivy на деплое).
- **Кто делает:** DS (приманка), MLSecOps (сканер).
- **План атаки:** `[приманка]` `demo/insecure/requirements_vuln.txt`: `flask==1.0.2`, `numpy==1.21.0`.
- **План митигации:** `pip-audit -r <req> -f json`; при CRITICAL/HIGH → exit 1; синк находок в реестр.
- **Демо:** пайплайн красный: «CRITICAL CVE-… in numpy».

### #3 — Supply Chain: pickle-RCE в весах
- **Актив:** файл весов (HF). **Поверхность:** закачка внешней модели. **Уязвимость:** pickle исполняет код при load.
- **Угроза:** RCE/бэкдор при загрузке. **Последствия:** захват хоста. **Риск:** Высокий.
- **Техники:** AML.T0010.003. **Gate:** **G3/G4** allow-list форматов + modelscan/picklescan.
- **Кто делает:** DS (приманка `.pkl`), MLSecOps (gate).
- **План митигации:** `model_gate` блок по расширению/магии (`.pkl/.joblib/.bin`→блок; разрешены `.safetensors/.onnx/.cbm/.txt`)
  + `modelscan -p <file>`. **Никогда не unpickle для проверки.**
- **Демо:** затягиваем `.pkl` → блок «unsafe format / suspicious opcode».
- **Честный предел:** трояны в *обученных весах* (не pickle) сканер не ловит → метка источника + HITL + атрибуция.

### #4 — Подмена артефакта перед деплоем
- **Актив:** модель, уезжающая в прод. **Поверхность:** CI/CD, MinIO. **Уязвимость:** нет проверки целостности.
- **Угроза:** подмена файла на вредоносный. **Последствия:** в прод чужая/битая модель. **Риск:** Высокий.
- **Техники:** T1195.002. **Gate:** **G4 + Registry** SHA-256.
- **План митигации:** SHA-256 считается при регистрации (CI-артефакт) → реестр; перед `docker run`
  пересчёт+сверка+cosign-verify; mismatch → деплой отменён, событие.
- **Демо:** руками портим файл в MinIO → деплой падает «hash mismatch».

### #25 — Видимость реестра (инфраструктурный актив)
- **Актив:** сам реестр. **Поверхность:** API/админка реестра. **Уязвимость:** нет единой точки правды.
- **Угроза:** Shadow-модели, потеря контроля. **Последствия:** регулятор без ответа «что в проде». **Риск:** Средний.
- **Техники:** NIST AI RMF. **Gate:** Registry (Postgres+UI).
- **План митигации:** таблицы `models/datasets/model_versions`; UI «Реестр» с фильтром по статусу/Tier; связь с findings/events.

### Audit Trail — единая история (infra, обязательно)
- **Актив:** журнал действий. **Уязвимость:** действия не логируются. **Угроза:** незаметные действия. **Риск:** Высокий.
- **План митигации:** `log_event(actor, role, action, asset, result, reason, details)` из всех сервисов; hash-chain; UI «История».
- **Демо:** на экране: добавлен датасет → скан1 ok → скан2 заблокировал → карантин; актор = реальная личность.

### Gate перед продом + Tier/HITL (G0/G4)
- **Актив:** прод, критичные модели. **Уязвимость:** автодеплой без ревью. **Угроза:** непроверенная HIGH-модель в проде. **Риск:** Высокий.
- **План митигации:** поле `Tier`; CI: HIGH без `approved_by` → стоп (`pending_hitl`); UI «Approve» только MLSecOps → событие → CI продолжает.
- **Демо:** LOW — автоматом; HIGH — карантин → Approve → прод.

## P1 — Низковисящие фрукты

### #1 — Data Poisoning
- **Актив:** `train.csv`. **Поверхность:** загрузка датасета. **Уязвимость:** нет валидации схемы/распределений.
- **Угроза:** отравление обучающих данных. **Последствия:** искажение скоринга, скрытый бэкдор. **Риск:** Высокий.
- **Техники:** AML.T0020. **Gate:** **G1**.
- **План атаки:** `[приманка]` `train_m1_poisoned.csv`: класс `fraud` раздут с 2% до 50%.
- **План митигации:** pandas — проверка схемы (колонки==эталон); `value_counts(normalize)`; сдвиг доли > порога → exit 1.
- **Демо:** подкладываем приманку → `[BLOCKED] class balance anomaly`.

### #2 — Утечка ПДн в обучающей выборке
- **Актив:** датасет, логи. **Поверхность:** загрузка данных. **Уязвимость:** нет DLP на PII.
- **Угроза:** сырые ПДн в обучении/хранилище. **Последствия:** 152-ФЗ/GDPR, штраф РКН. **Риск:** Высокий.
- **Техники:** T1530. **Gate:** **G1** regex (опц. Presidio).
- **План митигации:** regex на email/16-знач.карты/паспорт по колонкам → `[BLOCKED] PII detected`.
- **Демо:** колонка `email` в приманке → блок.

### #5 — Model Extraction
- **Актив:** поведение модели (IP). **Поверхность:** публичный API. **Уязвимость:** нет лимита, точные вероятности.
- **Угроза:** клонирование (distillation). **Последствия:** потеря IP. **Риск:** Высокий.
- **Техники:** AML.T0024. **Gate:** **G7**.
- **План митигации:** Redis rate-limit `>N/min → 429`; output reduction (`{"decision":"approve"}` вместо `0.8123`).
- **Демо:** `attack_sim.py` → 429 + всплеск в дашборде.

### #6 — DoS гигантским payload
- **Актив:** CPU/RAM. **Поверхность:** публичный API. **Уязвимость:** нет лимита размера. **Угроза:** отказ. **Риск:** Средний.
- **Техники:** T1499. **Gate:** **G7** Pydantic + лимит тела.
- **План митигации:** строгая схема (текст ≤ N), лимит размера запроса → `422/413` до модели.
- **Демо:** 10 МБ мусора → `413/422`, RAM не растёт.

### #11 — Evasion / аномальный вход
- **Актив:** API (антифрод). **Поверхность:** эндпоинт. **Уязвимость:** нет бизнес-валидации. **Угроза:** обход подобранным входом. **Риск:** Средний.
- **Техники:** AML.T0015. **Gate:** **G7** валидаторы.
- **План митигации:** Pydantic-валидаторы `amount>0`, `0≤age≤120` → `422`.
- **Демо:** `amount:-5000`/`age:250` → отбито до модели.

### #22 — RBAC / эскалация привилегий
- **Актив:** функции платформы (Approve/deploy/retire). **Поверхность:** API/UI. **Уязвимость:** нет разграничения ролей.
- **Угроза:** DS аппрувит свою HIGH-модель / дёргает админку. **Последствия:** обход HITL. **Риск:** Высокий.
- **Техники:** T1078. **Gate:** RBAC (`require_role`) + identity.
- **План митигации:** роли в `roles`; `require_role("MLSecOps")` на привилегиях; UI прячет кнопки; отказ → 403 + событие.
- **Демо:** DS жмёт Approve → `403` + событие `access_denied`.

### #23 — Версионирование и lineage
- **Актив:** модели/датасеты. **Поверхность:** реестр. **Уязвимость:** нет версий → нельзя откатить.
- **Угроза:** «DS уволился, не перевыпустить». **Последствия:** простой, нет аудита. **Риск:** Средний.
- **План митигации:** `model_versions(dataset_version, git_sha, sha256, run_id, ...)`; UI lineage + «откат на версию N».
- **Демо:** для прод-модели видно: датасет vX, коммит abc123, кто обучил.

## P2 — Practice-maxxing

### #9 — Typosquatting зависимостей
- **Актив:** сборочный конвейер. **Поверхность:** `requirements.txt`/PyPI. **Уязвимость:** нет allow-list имён.
- **Угроза:** установка пакета-двойника. **Последствия:** RCE на сборке. **Риск:** Средний. **Техники:** AML.T0010.003. **Gate:** **G3**.
- **План атаки:** `[приманка]` ветка с `pytirch`/`tenserflew`.
- **План митигации:** `dependency_gate` сверяет каждый пакет с белым списком → `Blocked: untrusted package`.
- **Демо:** ветка с опечаткой → красный gate.

### #12 — Утечка ПДн в логах
- **Актив:** `inference.jsonl`. **Поверхность:** логирование инференса. **Уязвимость:** пишем сырой запрос.
- **Угроза:** ПДн доступны DevOps. **Последствия:** 152-ФЗ. **Риск:** Средний. **Техники:** T1005. **Gate:** **G7** DLP.
- **План митигации:** middleware regex/Presidio маскирует карту `****-1234`, ФИО.
- **Демо:** открываем лог — ПДн замаскированы.

### #13 — Membership Inference
- **Актив:** API предсказаний. **Поверхность:** эндпоинт. **Уязвимость:** ответ высокой энтропии.
- **Угроза:** определить, был ли человек в обучении. **Последствия:** нарушение приватности. **Риск:** Низ/Сред. **Техники:** AML.T0024. **Gate:** **G7** output reduction.
- **План митигации:** общий `reduce_output()` — класс/округление вместо `predict_proba` 6 знаков.
- **Демо:** «сырой» vs «урезанный» ответ.

### #24 — Целостность Audit Log
- **Актив:** таблица `events`. **Поверхность:** БД/API лога. **Уязвимость:** записи можно изменить.
- **Угроза:** заметание следов. **Последствия:** нет расследования. **Риск:** Средний. **Техники:** T1070.
- **План митигации:** `prev_hash`/`row_hash = sha256(prev_hash+payload)`; верификатор; UPDATE/DELETE отозваны на БД-роли.
- **Демо:** правим строку руками → `verify_chain()` показывает разрыв.

### #26 — Подпись моделей / provenance
- **Актив:** артефакт модели. **Поверхность:** хранилище/деплой. **Уязвимость:** нет криптоподтверждения.
- **Угроза:** запуск неподписанной/чужой модели. **Последствия:** потеря доверия. **Риск:** Средний. **Техники:** T1195.002. **Gate:** **G4** cosign.
- **План митигации:** при релизе подпись артефакта/образа ключом (GH secret); прод запускает только при валидной подписи.
- **Демо:** неподписанная модель → деплой отклонён.

### #14 — Data/Concept Drift
- **Актив:** качество решений. **Поверхность:** прод-трафик. **Уязвимость:** нет мониторинга распределений.
- **Угроза:** деградация модели. **Последствия:** потеря денег до обнаружения. **Риск:** Средний. **Gate:** **G6** PSI/evidently.
- **План митигации:** монитор считает PSI прод vs train; `PSI>0.25` → алерт в UI/events.
- **Демо:** `prod_traffic_drifted.csv` → `DRIFT DETECTED`.

### #20 — Shadow AI / нет model card
- **Актив:** процессы, репутация. **Поверхность:** регистрация. **Уязвимость:** нет проверки документации.
- **Угроза:** модель выкатили втихую. **Последствия:** регуляторный риск. **Риск:** Средний. **Gate:** **G5**.
- **План митигации:** G5 проверяет полноту паспорта; нет → блок регистрации.
- **Демо:** регистрируем без карточки → блок «model card required».

### #19 — Training-Serving Skew
- **Актив:** качество предсказаний. **Поверхность:** рассинхрон `train.py`↔`serve`. **Уязвимость:** разная логика фич.
- **Угроза:** смещение скоров. **Последствия:** систематически неверные решения. **Риск:** Средний. **Gate:** **G4** consistency-тест.
- **План митигации:** pytest берёт N строк, прогоняет фичеинж из train и serve, сравнивает; расхождение → fail.
- **Демо:** ломаем расчёт возраста → тест падает.

## P3 — GenAI / агенты (доп. балл, если берём 4-ю модель)

### #7 — Prompt Injection (прямая)
- **Актив:** системный промпт/LLM. **Поверхность:** чат-эндпоинт. **Уязвимость:** вход не фильтруется.
- **Угроза:** перехват инструкций. **Последствия:** обход правил. **Риск:** Средний. **Техники:** AML.T0051/LLM01. **Gate:** **G7** guardrails.
- **План митигации:** перед LLM — классификатор/regex (`ignore previous instructions`, `system prompt:`) → отбой.
- **Демо:** инъекция в чат → blocked.

### #15 — Indirect Prompt Injection (RAG)
- **Актив:** LLM-агент через RAG. **Поверхность:** документы в vector-БД. **Уязвимость:** индексация без проверки.
- **Угроза:** скрытая инструкция в документе. **Последствия:** агент одобряет любой кредит. **Риск:** Высокий. **Техники:** LLM01/ASI01. **Gate:** **G1** для текста.
- **План митигации:** сканер при индексации ищет паттерны смены системного промпта → блок индексации.
- **Демо:** `loan_policy.md` со скрытой строкой → индексация заблокирована.

### #16 — Обход guardrails через кодирование
- **Актив:** LLM. **Поверхность:** чат. **Уязвимость:** фильтр смотрит только plaintext.
- **Угроза:** запрещёнка в Base64/Hex/Unicode. **Последствия:** обход фильтров. **Риск:** Средний. **Техники:** AML.T0043. **Gate:** **G7** нормализатор.
- **План митигации:** middleware декодирует Base64/Hex/Unicode → затем фильтр/LLM-Guard.
- **Демо:** Base64-запрос → после декода blocked.

### #17 — Кража системного промпта
- **Актив:** системные инструкции (IP). **Поверхность:** чат. **Уязвимость:** нет DLP на выходе.
- **Угроза:** выманивание секрета из промпта. **Последствия:** утечка IP. **Риск:** Средний. **Техники:** LLM07. **Gate:** **G7** output DLP.
- **План митигации:** regex на выходе ищет маркер-секрет → ответ заменяется на `[Заблокировано фильтром]`.
- **Демо:** «повтори слова выше» → секрет не утекает.

### #18 — Excessive Agency / Tool Misuse
- **Актив:** внутренние системы (БД, почта). **Поверхность:** инструменты агента. **Уязвимость:** агент сам исполняет деструктив.
- **Угроза:** через инъекцию вызвать `delete_user_account()`. **Последствия:** удаление данных. **Риск:** Высокий. **Техники:** LLM06/ASI02. **Gate:** **G7 + HITL**.
- **План митигации:** деструктивные tools требуют подтверждения оператора → «Требуется подтверждение (HITL)».
- **Демо:** просим удалить аккаунт → ждёт HITL.

### #21 — Token DoS / исчерпание бюджета
- **Актив:** бюджет LLM, доступность. **Поверхность:** чат. **Уязвимость:** нет лимита токенов/таймаута.
- **Угроза:** прожиг кредитов. **Последствия:** перерасход, отказ. **Риск:** Средний. **Техники:** LLM10. **Gate:** **G7** квоты.
- **План митигации:** `max_tokens`, таймаут на уровне FastAPI; обрыв запроса.
- **Демо:** «поэма 50000 слов» → обрыв по лимиту.
