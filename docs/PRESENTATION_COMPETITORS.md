# Сравнение с аналогами — слайды презентации

> Позиционирование MLSecOps (Alfa case). Не маркетинговый бенчмарк — сравнение по **заявленным возможностям платформы** из канона проекта.

---

## Слайд 1. Аналоги одной строкой

| Аналог | Что это |
|--------|---------|
| **MLflow** (+ MinIO) | Эксперименты, Registry, артефакты — без банковского допуска в прод |
| **Kubeflow / Airflow** | Оркестрация ML-пайплайнов — мало встроенной ИБ-реестра и HITL |
| **Snyk / SonarQube** | SAST/SCA для кода — не видят lineage «данные → модель → прод» |
| **Protect AI / standalone ModelScan** | Скан файла модели — точечно, без датасетов и audit |
| **Evidently / Arize / Fiddler** | Мониторинг drift и качества в проде — слабый pre-prod gate + Tier |
| **SageMaker / Vertex AI** | Облачный MLOps end-to-end — vendor lock-in, общий compliance |
| **Сборка «своими руками»** | MLflow + Jenkins + сканеры — дорого стыковать и поддерживать |

**Мы:** **MLSecOps Gatekeeper** — слой безопасности **над** MLOps: гейты G0–G7, реестр, CI-канон, HITL, audit.

## Слайд 3. Плюсы — мы vs аналоги

| | **Наши плюсы** | **Плюсы аналогов** |
|--|----------------|-------------------|
| **vs MLflow** | Один вход: verify → CI → статус в банке; неподделываемый audit; quarantine | Зрелый стандарт MLOps, экосистема, привычен DS |
| **vs Snyk/Sonar** | Сквозной актив: данные + код + deps + **модель** + деплой + прод | Глубокая база CVE, IDE-интеграции, enterprise SAST |
| **vs Arize/Evidently** | Блокировка **до** прода + HITL; связь с run и датасетом | Сильные дашборды drift, алерты, A/B в проде |
| **vs Protect AI / scan-only** | Полный lifecycle, не один файл | Быстрый point-scan, коммерческие базы угроз ML |
| **vs SageMaker/Vertex** | Под банк: свой реестр, on-prem, прозрачные гейты | Managed scale, AutoML, billing одного вендора |
| **vs «сборка руками»** | Готовая схема G0–G7, один Gatekeeper, документированный канон | Гибкость «выбрать лучший в классе» по каждому слою |

---

## Слайд 4. Три сообщения для зала

1. **Не заменяем MLflow** — делаем его **безопасным для банка**.  
2. **Не ещё один сканер** — **оркестратор** проверок и решений с audit.  
3. **Не только мониторинг** — **stop-the-line** до прода + ручной контроль рискованных Tier.

## Speaker notes (15 сек)

> Рынок даёт либо MLOps без банковского допуска, либо точечные сканеры, либо мониторинг после выката.  
> Мы соединяем это в **одном Gatekeeper**: от датасета до прода с гейтами, HITL и неизменяемым журналом — поверх привычного MLflow.
