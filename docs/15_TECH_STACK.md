# 15 — Технологический стек и обоснование

| Слой | Технология | Почему |
|---|---|---|
| Язык | **Python 3.11** | экосистема ML/ИБ-инструментов, единый язык для гейтов/бэка/инференса |
| Бэкенд / Gatekeeper | **FastAPI** | быстрый async REST, Pydantic-валидация из коробки, удобно для `/verify` и инференса |
| UI | **Streamlit** | быстрый веб-UI за дни, достаточно для дашбордов/форм/таблиц |
| Реестр + аудит + RBAC | **PostgreSQL** | транзакции, JSONB для паспорта/evidence, UNIQUE-констрейнты, отзыв UPDATE/DELETE для append-only |
| Хранилище артефактов | **MinIO (S3)** | S3-совместимо, **Object Lock (WORM)** для неизменяемости прода |
| Rate-limit / кэш | **Redis** | счётчики rate-limit (G7), кэш выпадашек MLflow |
| Трекинг/реестр ML | **MLflow** (Tracking + Model Registry) | стандарт MLOps, dataset tracking (digest+SHA), aliases для релиза; ставим **за auth-прокси** (нет своего RBAC) |
| Идентичность | **OIDC/JWT-прокси** (oauth2-proxy / Authelia / Keycloak / кастом) | единый SSO, серверный штамп личности → неподделываемая атрибуция |
| CI/CD | **GitHub Actions** + **self-hosted runner** | требование команды + локальный запуск джоб на демо |
| Контейнеризация | **Docker / docker compose** | один `docker compose up` поднимает всё; образ на каждый гейт |
| Скан секретов (G2) | **gitleaks** | зрелый детектор секретов в коде/истории |
| SAST (G2) | **bandit** | статанализ Python на небезопасные паттерны |
| SCA / CVE (G2) | **pip-audit** | CVE в Python-зависимостях по advisory-БД |
| Скан образов (G2 deploy) | **trivy** | CVE в Docker-образе/ФС; единственный запуск — на деплое |
| Supply (G3) | кастомный чекер + allow-list, `pip --require-hashes` | анти-typosquatting, пиннинг, доверенный источник |
| Скан весов (G4) | **modelscan (Protect AI) / picklescan** | вредоносные opcode/импорты в артефактах (анти-pickle-RCE) |
| Целостность/подпись (G4) | **hashlib (SHA-256)** + **cosign/sigstore** | целостность артефакта и provenance, проверка перед `docker run` |
| Consistency (G4) | **pytest** | тест train↔serve на расхождение фич |
| Данные (G1) | **pandas** + **regex** (+опц. **Microsoft Presidio**) | схема/баланс/типы + поиск ПДн |
| Дрейф (G6) | **evidently** (PSI) | мониторинг распределений прод-трафика |
| Валидация рантайма (G7) | **Pydantic** | строгие схемы входа, диапазоны, лимиты |

## Принципы выбора

- **Берём готовое, докручиваем безопасность.** Пример: MLflow удобен, но без RBAC — поэтому не
  публикуем его наружу, а ставим за auth-прокси с серверной идентичностью.
- **Изоляция инструментов по образам.** У каждого гейта свой тулчейн и версии — не смешиваем.
- **Минимум зависимостей на гейт.** `requirements.txt` гейта содержит только его инструменты.
- **Никаких секретов в коде.** Ключи cosign/токены — в GitHub Actions secrets / `.env` (вне VCS).
